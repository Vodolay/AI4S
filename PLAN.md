# NeuroMPS: 25-Day Plan for the AI4S Organ-on-Chip Challenge

**Deadline:** Oct 10, 2026 (submit by Oct 9 to be safe)
**Budget:** 20 half-days ≈ 80 hours, Sep 15 → Oct 10
**Working style:** You act as PI/reviewer; Claude Code does the building; Claude Cowork drafts the report, writeup, and video script.

## What we're building

One repo, two layers, one story:

1. **NeuroMPS-Data (Plan A′)** — a standardized, provenance-tracked dataset of neural MEA/chip recordings assembled from public sources, with a draft data standard and a rat→human transfer study.
2. **NeuroMPS-Twin (Plan B′)** — a spiking-network digital twin of an asymmetric two-compartment neural chip, calibrated on the real data, with simulation-based inference that recovers connectivity and drug effects from MEA features.

Narrative for judges: *raw recordings → standardized data asset → calibrated digital twin → predictive inference.* This mirrors the supporting organization's stated roadmap (standardization, data assetization, digital twins for neural drug development).

**Scope guardrails (write these into every prompt):** research decision-support only; no efficacy, safety, or clinical claims; no scraping of gated content; every number in the report must trace to a script output.

## Data sources (Phase 0 confirms each)

| Source | What it gives | Use |
|---|---|---|
| Hyvärinen et al., *Scientific Data* 2022 — hPSC vs rat cortical MEA dataset (raw + spike times + analysis code) | Maturation time series + pharmacology (glutamatergic/GABAergic agonists/antagonists, Na-channel blockers) | Core of A′; calibration target for B′ |
| US EPA ToxCast MEA neurotoxicity assays (acute + network formation), via CompTox Dashboard / invitrodb | Dose–response MEA features for hundreds of chemicals, rat cortical | Scale for mechanism model; QC of harmonization |
| Supplementary tables from MEA pharmacology papers (e.g., Utrecht/IRAS dose–response studies) | Extra compounds & platforms | Optional; only if extraction is cheap |
| Axon-diode / compartmentalized chip papers (Sorbonne lineage) | Geometry, channel counts, reported directionality metrics | Design parameters for B′, no raw data needed |

If a source turns out to be gated or too large, log it in `data/SOURCES.md` and move on — do not let Phase 0 exceed 2 half-days.

## Schedule

Half-days are numbered HD1–HD20. Five calendar days are unallocated buffer; use them when a phase overruns.

### Phase 0 — Setup & data acquisition (HD1–HD2, Sep 15–16)

- HD1: Init repo, `CLAUDE.md`, `pyproject.toml`, CI (GitHub Actions running `pytest` + a smoke `run_all.py --quick`). Claude Code prompt: *"Scaffold the repo per PLAN.md. Add a `fetch/` module with one function per source that downloads to `data/raw/<source>/`, records URL, license, SHA256, and download timestamp into `data/raw/MANIFEST.json`. Do not process anything yet."*
- HD2: Run fetchers. Inspect what actually arrived. Decide raw-vs-preprocessed for the Sci Data set (if raw MEA is multi-GB and slow, use provided spike times — note the choice in `SOURCES.md`). Read the ToxCast MEA assay component descriptions and pick the feature set.

**Gate:** you can `ls data/raw` and see real files from ≥2 sources with licenses recorded.

### Phase 1 — Schema, ETL, provenance, QC (HD3–HD6, Sep 17–22)

- HD3: Write `neuromps_schema.json` + `STANDARD.md`. Fields: source, license, cell_source (species, type, donor/line), platform, well/chip id, day_in_vitro, compound (name, CAS/InChIKey), dose, exposure_min, recording_duration, feature vector (MFR, burst rate, burst duration, network burst rate, % spikes in bursts, synchrony index, ISI CV), QC flags. Model it on the intestine-on-a-chip group standard's structure (scope, terminology, technical requirements, QC).
- HD4: Shared feature extractor `features/mea.py` that computes the vector from spike trains. It **must** be the same function the twin uses later. Unit tests on synthetic spike trains with known statistics.
- HD5: ETL for Sci Data set → processed parquet. ETL for ToxCast MEA → same schema (map their component names to ours; keep a `mapping.csv`).
- HD6: QC module: outlier flags, missingness, replicate divergence, plus per-record `provenance.json` (source hash → transform chain → output hash). Data card with counts per species/compound/platform.

**Gate:** `python run_all.py --stage data` regenerates `data/processed/neuromps.parquet` from raw with zero manual steps; `pytest` green.

### Phase 2 — Models (HD7–HD10, Sep 23–28)

- HD7: Baselines. Task 1: mechanism-class classification (GABA-A antagonist / glutamatergic agonist / Na-channel blocker / inactive) from the MEA feature delta vs baseline. Logistic regression + gradient boosting; nested CV grouped by well/culture; report balanced accuracy + calibration.
- HD8: Task 2 (the scientific headline): **rat → hPSC transfer.** Train on rat, test on hPSC; compare against training on hPSC alone. Compute per-feature species shift; identify species-invariant features. Try simple domain adaptation (feature standardization per species, CORAL) and report honestly whether it helps.
- HD9: Uncertainty: conformal prediction sets on Task 1; bootstrap CIs everywhere. Ablations on feature subsets.
- HD10: Figures + `metrics.json`. Write results section draft (Cowork). Review every claim against outputs.

**Gate:** `metrics.json` and 4–5 figures regenerated by `run_all.py --stage models`.

### Phase 3 — Digital twin (HD11–HD16, Sep 29 → Oct 5)

- HD11: Brian2 model: two populations (e.g., "cortical" → "striatal"-like, or cortical → cortical), each 200–500 LIF/AdEx neurons with 80/20 E/I, intra-population recurrent connections, and **directional** inter-population projections through N "diode" channels (parameter: forward vs backward connection probability ratio). Poisson background drive. Validate: spontaneous bursts appear at plausible rates.
- HD12: MEA simulator: map neurons to virtual electrode positions per compartment; produce spike trains per electrode; run the **same** `features/mea.py`. Calibrate baseline parameters so simulated features fall within the real hPSC/rat baseline distributions (record which parameters were tuned and how).
- HD13: Drug perturbation knobs: GABA-A conductance scale, AMPA/NMDA scale, Na-channel/spike-threshold scale. Confirm each moves features in the direction seen in the real pharmacology data (qualitative validation table).
- HD14: Simulation-based inference with `sbi` (NPE). Prior over {forward/backward ratio, inter-pop strength, 3 drug knobs}. Simulate ~5–20k runs (cache to disk; use `--quick` for CI). Train posterior estimator.
- HD15: Inference on (a) simulated held-out conditions (posterior coverage check), (b) **real** pharmacology recordings from Sci Data — show posteriors recover the correct drug knob direction. This is the twin's "predictive simulation" result.
- HD16: Directionality experiment: show inference can distinguish symmetric vs asymmetric connectivity from features alone, and how many electrodes/how long a recording is needed. Figures.

**Gate:** `run_all.py --stage twin --quick` runs in <10 min on CPU; full run documented with timing.

### Phase 4 — Demo, report, writeup, video (HD17–HD20, Oct 6–9)

- HD17: Streamlit app: tab 1 browse the data asset with QC flags & provenance; tab 2 drug-mechanism prediction with conformal set; tab 3 twin — sliders for connectivity/drug knobs → simulated features + posterior plot. Keep it simple and robust.
- HD18: `TECHNICAL_REPORT.md` (Cowork draft, your edit): problem, data standard, data asset, models, twin, results, limitations, reproducibility, AI-assistance disclosure. `KAGGLE_WRITEUP.md` summarizing it. `CITATIONS.md`, `THIRD_PARTY.md`, license.
- HD19: **Fresh-environment reproducibility run** (new venv or Docker): clone → `pip install` → `python run_all.py --quick` → app launches. Fix anything that breaks. Record demo video (≤5 min, script from Cowork): 30 s problem, 60 s data asset + standard, 60 s transfer result, 90 s twin + inference, 30 s reproducibility.
- HD20: Submit Kaggle Writeup with public repo link, video link, report. Buffer for last fixes.

## Claude Code workflow rules

1. **One phase = one branch, one PR.** You review the PR diff and the regenerated outputs, not the agent's summary.
2. **Start each session with:** *"Read CLAUDE.md and PLAN.md. We are in Phase N, HDk. State what exists, what the gate requires, then propose the next 3 concrete steps before writing code."*
3. **Every result-producing script writes to `outputs/` and appends to `metrics.json`.** No number goes into the report from a notebook.
4. **Ask the agent to write the test before the feature** for `features/mea.py`, QC flags, and the MEA simulator.
5. **Verification prompts** (use liberally): *"Run it and paste the actual output."* / *"Which assumption here could make this result wrong? Add a check."*
6. **Cowork** for: report drafting from `metrics.json` + figures, video script, data card, and turning `STANDARD.md` into a polished document. Always feed it the real outputs, never let it invent numbers.
7. **Daily 10-minute close:** update `PROGRESS.md` with what's done, what's blocked, and the next HD's first task. Next session starts by reading it.

## Risk register

| Risk | Mitigation |
|---|---|
| Raw MEA data too large/slow | Use dataset's provided spike times & metrics; note in SOURCES.md |
| ToxCast features not harmonizable with Sci Data features | Keep ToxCast as a separate "platform" in the asset; run mechanism model per platform; report harmonization as a limitation and a standard requirement |
| Transfer result is negative (rat doesn't predict hPSC) | That is a publishable finding — report it with feature-shift analysis |
| Twin doesn't reproduce real bursting | Reduce to single-population first; directionality comes second |
| sbi training too slow | Reduce simulator size, use summary features (already low-dim), cap at 5k sims |
| Time overrun in Phase 3 | Cut HD16 (directionality) before cutting HD15 (real-data inference) |
